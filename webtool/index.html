El estilo/rate/gate se aplican en vivo. Recordá «Guardar en NVS» para que el slot quede fijo en la placa.

Un paquete de sonido (.tolhuin.json) junta TODOS los timbres (incluidos los USR con su familia de oscilador), los patrones de batería (con sus nombres, volumen y motor) y los slots de arpegiador (con sus nombres). Sirve para respaldar tu configuración o publicar paquetes de sonido en la web.

Desconectá primero el editor — el puerto serie no se puede compartir.

Este navegador no soporta Web Serial (usá Chrome o Edge de escritorio). Serví esta página por HTTPS o localhost.

El binario lo define manifest.json (ver el README de webtool/ para generarlo con arduino-cli y publicarlo).
